# Self-Designed Autograd

A neural-network framework implemented from scratch, covering automatic
differentiation, feed-forward networks, convolutional networks, recurrent
networks, normalization, and residual architectures.

## Development Stages

| Branch | Description |
|---|---|
| `pa1-core-autograd` | Core autograd and feed-forward neural networks |
| `pa2-cnn` | Convolutional neural-network extension |
| `pa3-rnn` | Recurrent and sequential-network extension |
| `pa4-norm-residual` | Normalization and residual-architecture extension |
